# Meta Quest 2: firmware analysis tools

Offline, read-only tools that inspect the owner's own Meta Quest 2 v2.7 firmware. No firmware
content is included: [v27-dt/](v27-dt/) covers the device tree (`extract-v27-dt.sh` regenerates
it) and [v27-stage1/](v27-stage1/) the boot image and verified-boot data.
