# Meta Quest Pro

Follows once SteamOS boots on the Meta Quest 3. Build and research work only so far: no FrameShift
image has run on a Quest Pro, and the project has no Quest Pro unit yet.

- **Platform:** Qualcomm XR2+ Gen 1.
- **Kernel:** the same Meta source tree as the Meta Quest 2, built with its own configuration. The
  kernel gate passes for the extra options SteamOS needs first.
- **Approach:** do the work on the Quest 2 and Quest 3, then port it.
- **Safety:** the eye- and face-tracking infrared illuminators must stay under control equivalent
  to Meta's (eye safety). The cooling and the rear battery differ from the Quest 2.
