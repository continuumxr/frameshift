# Relays

FrameShift is run with an independent adversarial review: the engineering side writes
relays (`FS-A-NNN`) and the reviewer answers with numbered rulings (`FS-R-NNN`), which are
binding until superseded. That review dialogue, its relays, rulings and evidence bundles, is
kept private (PM decision, J-167). Other documents still cite relay and ruling numbers as
identifiers; the documents themselves are not part of this public copy.
